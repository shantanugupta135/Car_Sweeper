# Admin Operations Portal Design Specification

## 1. Overview
The Admin Operations Portal transforms `Car_Sweeper-main` into a dedicated web application for business owners and operational managers of CarsGlow / SmartCar Care. Consumers (Car Owners) and Cleaners access the platform via the mobile app (`sweeper-clean-expoapp`), while the Web App provides centralized management over societies, cleaner onboarding/assignments, consumer subscriptions, daily cleaning quality control, and business analytics.

## 2. Architecture & Data Layer Alignment

### Two-Tier Web Architecture
- **Single Page Application (SPA):** Next.js 14+ / React 19 web app housed in `Car_Sweeper-main`.
- **Admin Shell Navigation:** Driven by `lib/navigation-context.tsx` with top navigation header (`components/admin/admin-header.tsx`) and collapsible dark sidebar (`components/admin/admin-sidebar.tsx`).
- **Data Layer Seam:** Shared TypeScript contracts matching mobile app API contracts (`lib/types/api.ts`) and mock backend service (`lib/services/admin-service.ts`), configurable via `NEXT_PUBLIC_API_MODE=('mock' | 'real')`.

### Role & Access Control
- `admin`: Business owner / Ops manager accessing the Web App.
- Cleaners and Consumers do not log into the Web App. Cleaners are onboarded directly by Admin via the Admin Portal and provided login credentials for the mobile app.

## 4. Operational Modules & UI Components

### A. Executive Overview & Analytics (`components/admin/screens/admin-overview.tsx`)
- **Key Metrics Grid:** Monthly Recurring Revenue (MRR), Active Subscribers, Daily Clean Completion Rate, Total Active Cleaners, Open Complaints.
- **Visual Analytics:** 7-Day Completion Rate bar chart, Revenue by Society breakdown, Quick Alerts panel.

### B. Cleaner Management & Onboarding (`components/admin/screens/admin-cleaners.tsx`)
- **Cleaner Directory Table:** List showing cleaner name, phone, assigned society, tower list, daily quota (e.g. 24/30 cars), rating, and status.
- **Add New Cleaner Drawer (`components/admin/modals/add-cleaner-modal.tsx`):**
  - Personal info (Name, Phone, Aadhaar/ID).
  - Society & Tower assignment picker.
  - Set daily capacity limit.
  - Credential Generator: Generates Phone + 6-digit PIN for cleaner's mobile login.
- **Cleaner Re-assignment Modal:** Modify assigned society or towers dynamically.

### C. Society Onboarding & Management (`components/admin/screens/admin-societies.tsx`)
- **Society List & Card Grid:** Display societies with total registered subscribers, active assigned cleaners, and tower coverage.
- **Onboard Society Modal (`components/admin/modals/add-society-modal.tsx`):** Form to add new apartment society, city/area, and tower list.

### D. Consumer & Vehicle Directory (`components/admin/screens/admin-consumers.tsx`)
- **Searchable Table:** Filter by society, tower, plan, status (`Active`, `Paused`, `Expired`).
- **Consumer Detail Drawer:** Customer profile, vehicle list with parking bay numbers, subscription status, and wash history log.

### E. Live Daily Cleaning Monitor & Photo Audit (`components/admin/screens/admin-daily-monitor.tsx`)
- **Live Cleaning Queue:** Real-time list/grid of today's washes, filterable by society, cleaner, and status (`Pending`, `In Progress`, `Completed`, `Skipped`).
- **Photo Inspection Modal (`components/admin/modals/photo-inspection-modal.tsx`):**
  - Side-by-side view of **Before Wash** and **After Wash** photos submitted by cleaner.
  - One-click "Approve Wash" or "Flag Issue / Request Re-wash".

### F. Complaint Resolution Desk (`components/admin/screens/admin-complaints.tsx`)
- **Ticket Queue:** Open complaints grouped by urgency and society.
- **Resolution Drawer:** Inspect issue description + photos, trigger re-wash, reassign cleaner, or issue wallet credit to consumer.
